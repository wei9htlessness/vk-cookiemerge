Скрипт для игры в ВК "Соединяй печеньки" [vk.ru/cookiemerge](https://vk.ru/cookiemerge)    
Для браузерного расширения Tampermonkey. Также может работать на мобильных браузерах (не приложение ВК)

## УСТАНОВКА: Поставьте для браузера расширение Tampermonkey и разрешите ему работу со скриптами, если это необходимо. На этой странице найдите [Releases](https://github.com/wei9htlessness/vk.cookiemerge/releases) и кликните по .js файлу, расширение должно подтянуть скрипт и установить его. Если этого не произошло, то скачайте файл, откройте расширение и установите его самостоятельно через копировать вставить или перетаскивание файла в окно расширения. Обновите страницу ВК, зайдите в игру и увидите меню скрипта. Ниже объяснение кнопок


"СТАРТ" (клавиша Z) - включает или отключает слияние печенек    
"ПОКУПКА" - покупает печенье указанного уровня, если "СТАРТ" работает    
"СБРОС 12" - продает последнее печенье, когда скрипт пытается купить новое печенье, а места нет, работает при "ПОКУПКА"      
"ТАЙМЕР" - отключает "СТАРТ" при окончании таймера, который вызывается при печенькопаде или фиксации цен      
"АВТОСЕЙВ" - каждые 20 слияний печенек открывает и закрывает окно улучшения тарелок для сохранения
