Скрипт для игры в ВК "Соединяй печеньки" (vk.ru/cookiemerge)    
Для расширения Tampermonkey  


## "СТАРТ" (клавиша Z) - включает или отключает слияние печенек
## "ПОКУПКА" - покупает печенье указанного уровня, если "СТАРТ" работает
## "СБРОС 12" - продает последнее печенье на 12 тарелке, когда скрипт пытается купить новое печенье, но места уже нет, работает при активной "ПОКУПКА"
## "ТАЙМЕР" - отключает "СТАРТ" при окончании таймера, который вызывается при печенькопаде или фиксации цен
## "АВТОСЕЙВ" - каждые 20 слияний печенек открывает и закрывает окно улучшения тарелок для сохранения сессии
